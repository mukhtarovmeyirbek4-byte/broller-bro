# BROLLER BRO

Обучающий сайт для начинающих фермеров на русском и узбекском языках (кириллица и латиница).

## Как открыть

Дважды щёлкните по файлу `index.html`, и сайт откроется в браузере. Устанавливать ничего не нужно.
График на странице «Вес по дням» загружается из интернета, а всё остальное работает и без него.

## Что где лежит

| Что хотите изменить | Какой файл открыть |
|---|---|
| Русские тексты | `lang/ru.js` |
| Узбекские тексты (кириллица) | `lang/uz.js` |
| Узбекские тексты (латиница) | `lang/uz-latn.js` |
| Вес и корм по дням (Ross 308, Cobb 500) | `data/breeds.js` |
| В какие дни какой корм (старт, рост, финиш) | `data/phases.js` |
| Температура в птичнике и под лампой по дням | `data/climate.js` |
| Свет и темнота по дням | `data/light.js` |
| Цены и цифры по умолчанию в калькуляторе | `data/defaults.js` |
| Нормы для расчёта птичника (кормушки, поилки, лампы) | `data/area.js` |
| Телефон для рекламы, группа и ник в Telegram | `data/site.js` |
| Цвета и оформление | `css/style.css` (блок `:root` в начале) |
| Описание страниц в Google, Яндексе и Telegram | строки `meta.…` в конце файлов `lang/*.js` и `<meta name="description">` в начале каждого `.html` |
| Картинка для ссылки в Telegram и значок сайта | `img/og-image.png`, `img/icon-*.png`, `img/logo-128.png`, `img/favicon-32.png` (сделаны из аватарки) |

Записи «Дневника партии» и «Моя партия» хранятся в браузере у каждого фермера, на сервер они не отправляются.

Файлы можно открывать любым текстовым редактором (TextEdit, VS Code, Блокнот).

## Как поменять текст

В файле языка каждая строка выглядит так:

```js
"nav.feeding": "График кормления",
```

Слева ключ, его **не трогайте**. Справа текст в кавычках, его меняйте. Кавычки и запятую в конце оставьте на месте.

## Как поменять норму

В `data/breeds.js` каждая строка выглядит так: `[день, вес в граммах, корм в граммах за этот день]`

```js
[21, 963, 112],
```

## Как добавить третий язык

1. Скопируйте `lang/ru.js` в новый файл, например `lang/en.js`.
2. Внутри замените `window.LANG.ru` на `window.LANG.en` и переведите тексты.
3. Во всех `.html` файлах рядом с `<script src="lang/uz.js"></script>` добавьте строку `<script src="lang/en.js"></script>`.

Кнопка нового языка появится в шапке сама.

## Как добавить породу

В `data/breeds.js` скопируйте блок `cobb500: { ... },`, дайте ему новое имя (например `hubbard: {`) и впишите свои цифры.
Новая порода сама появится в списках и на графике.
